# 问数助手

业务同事直接用中文提问，回答卡上写清系统怎么理解的，下面可以继续下钻。

![商业版问数助手：理解 chip、图表、数据表、结果解读与下钻](/img/analytics/commercial-ask-assistant.png)

:::info 版本说明
**问数助手**（对话式问数页）属于商业版。开源版的问数入口在建模工作台的「问数验证」里，用途是发布前逐题核对模型建得对不对。两者共用同一个查询引擎。详见[开源版与商业版](../open-source-vs-commercial.md)。
:::

## 一次提问经历了什么

```text
用户提问
  → 流式阶段推送（理解问题 / 生成 / 校验 / 翻译 / 执行）
  → 返回图表 + 数据表 + 系统理解说明
  → 可继续追问、下钻或改口径
```

「理解问题」阶段完成时会带上模型认出的**语义成员**，用户在结果出来之前就能看到系统把话听成了什么。

## 系统理解说明（理解 chip）

回答卡上的 chip 显示系统自己补上的理解。例如把「销售」认成「销售金额」，系统会把这件事**说出来**，而不是默默替用户做决定。

![商业版问数助手：期间比与自动理解提示](/img/analytics/commercial-period-ratio.png)

同比、环比按**带符号的增长率**展示。

## 默认时间窗

问题没写时间范围时，系统按配置补最近 N 天：

- 问题里明确说了的时间**一个字不动**
- 补上的时间窗在回答上**可见**
- 用户可以**一键改回不限时间**

这条规则的目的是避免全表扫描，同时不让补上的口径变成隐形假设。

## 多轮改写

多轮改写默认开启，只读取**同一会话、同一 Release、同一业务范围内上一轮成功的语义查询**，并且有两道确定性门：

1. 原话已经点名指标就不改写
2. 改写后多出原话没有的分组维度就作废回退

> **改写只能补口径，不能替用户新增问题。**

## 下钻与重跑

下钻在**文本 S2SQL** 上做确定性编辑，支持：

- 换过滤值
- 增减分组维度
- 换指标
- 换时间窗

编辑会保住原查询的时间粒度与期间比形状。**形状不支持时明确拒绝，不静默降级**。

## 结果解读

结果返回之后可以异步生成一段文字解读。它受严格约束：

- **只允许复述结果里字面出现过的数字**
- 禁止自行计算合计、占比或同环比
- 默认关闭；开启后不推迟结果返回

## 报表

满意的回答可以钉成卡片，按项目归档成报表，随时刷新取最新数字，可整页导出 Excel。

![商业版报表：钉住的问数结果，可刷新与导出](/img/analytics/commercial-reports.png)

## 助手级运行配置

单次请求可以覆盖部署默认值：

| 配置 | 作用 |
|---|---|
| 返回行数 | 结果上限 |
| 默认时间窗 | 未指定时间时补多少天 |
| 多轮改写 | 是否启用 |
| 自洽次数 | 生成的自洽校验轮数 |
| 模型与温度 | 覆盖 Chat 模型端点与温度 |

留空即跟随部署默认，因此不改变既有部署的行为。
