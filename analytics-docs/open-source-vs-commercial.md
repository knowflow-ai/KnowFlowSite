# 开源版与商业版

开源版给的是**建模能力和查询引擎**。它自带一套完整的建模工作台，四步走完就能发布一份可用的语义模型，并在「问数验证」里用自然语言试问、逐题核对结果。

它不提供面向业务用户的问数产品面。**日常提问的对话页、把回答钉成报表、按人分配数据权限**，这三件事在商业版 KnowFlow 里。

## 能力对比

| | 开源版 | 商业版 |
|---|---|---|
| 建模工作台（数据源、语义建模、问数验证、问数反馈） | ✅ | ✅ |
| AI 一键建模、别名与值字典建议 | ✅ | ✅ |
| 发布、版本回滚、发布前质量报告 | ✅ | ✅ |
| S2SQL 编译、治理关卡、只读 Guard、查询 API | ✅ | ✅ |
| PostgreSQL / MySQL / 上传表格，多数据源 | ✅ | ✅ |
| 词汇缺口收件箱、Golden Suite、诊断导出 | ✅ | ✅ |
| **问数助手**：对话式提问、多轮追问、下钻、结果解读、会话分享 | ❌ | ✅ |
| **报表**：把回答钉成卡片、按项目归档、刷新重跑、导出 Excel | ❌ | ✅ |
| **项目授权与数据范围**：多用户 RBAC、行级与列级权限 | ❌ | ✅ |
| 与知识库、Agent、企业账号体系打通 | ❌ | ✅ |
| 登录方式 | 单用户 + 可选共享口令 | 企业账号、LDAP / OIDC、企业微信 |

两者共用同一份语义模型与同一个查询引擎。

## 商业版长什么样

业务同事直接用中文提问，回答卡上写清系统怎么理解的，下面可以继续下钻。

![商业版问数助手：理解 chip、图表、数据表、结果解读与下钻](/img/analytics/commercial-ask-assistant.png)

同比环比按带符号的增长率展示。紫色 chip 是系统自己补的理解——它把「销售」认成销售金额，并且把这件事说了出来。

![商业版问数助手：期间比与自动理解提示](/img/analytics/commercial-period-ratio.png)

满意的回答钉成卡片，按项目归档成报表，随时刷新取最新数字，可整页导出 Excel。

![商业版报表：钉住的问数结果，可刷新与导出](/img/analytics/commercial-reports.png)

商业版还提供项目级授权与行列级数据范围，同一个项目里不同的人看到的行和列由授权决定。
