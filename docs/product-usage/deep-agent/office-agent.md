# 办公 Agent、技能与记忆

v2.6.0 让 Deep Agent 从“给出带引用的回答”走到“交付能直接使用的文件”。本文介绍这一版本新增的六项能力，以及部署时需要确认的配置。

| 能力 | 一句话说明 |
| --- | --- |
| [办公文档交付](#办公文档交付) | Agent 直接生成 Word、PowerPoint、Excel 文件，对话内预览和下载 |
| [隔离沙箱](#隔离沙箱) | 每个会话一个断网的工作区，附件自动放入，删除会话时清理 |
| [技能目录](#技能目录) | 管理员上传技能包，用户在聊天框用 `@` 点名使用 |
| [长期记忆](#长期记忆) | 跨会话记住偏好与事实，推断出的记忆先确认再使用 |
| [运行中插话](#运行中插话) | Agent 执行时继续输入，补进当前轮或排到下一轮 |
| [思考开关](#思考开关) | 在助手设置里统一控制模型是否先思考再回答 |

## 办公文档交付

KnowFlow 内置三个办公文档技能，随产品提供，无需安装：

| 技能 | 生成的文件 |
| --- | --- |
| `office-docx` | Word 文档（.docx） |
| `office-pptx` | PowerPoint 演示文稿（.pptx） |
| `office-xlsx` | Excel 表格（.xlsx、.csv 等） |

使用时把回答方式切到 **Agent**，在需求里写明要什么文件即可，不需要额外点名。Agent 会根据需求自动加载对应技能，例如：

> 根据我 @ 的三份季度周报，做一份 8 页左右的管理层汇报 PPT，每页一个结论，数字都要来自材料。

> 把上传的报价单整理成一张 Excel，按供应商分 sheet，最后一列算含税总价。

生成的文件会出现在回答下方的 **生成的文件** 列表里，每个文件是一张卡片：

- 点击卡片，右侧抽屉会就地预览 Word、Excel、PPT、PDF、图片和文本文件；
- 卡片上的下载按钮可以把文件保存到本地；
- 浏览器无法预览的格式会提示下载后查看。

:::tip 从知识库抽字段做台账，用结构化抽取
如果任务是“从多份合同里按字段提取信息，生成台账”，请 `@结构化抽取`。它会让每个值都对齐原文并保留引用。办公技能更适合整理、计算和排版类的自由格式文件。
:::

## 隔离沙箱

办公文档在 Agent 沙箱中生成。v2.6.0 起沙箱默认开启：

- **每个会话一个工作区**，彼此隔离；
- **断网运行**，沙箱内的代码无法访问外部网络；
- 对话中上传的附件会**自动放进工作区**，供 Agent 读取；
- 删除会话时，工作区一并清理；会话长时间空闲后，沙箱也会被回收。

正在进行中的回答不能追加附件，请等本轮结束后再上传。

## 技能目录

除了内置能力，管理员还可以把团队自己的工作方法打包成技能，安装到 KnowFlow 中供所有人使用。

### 安装技能（管理员）

1. 在顶部导航进入 **Agent 技能** 页面。
2. 点击 **安装技能**，上传一个 `.zip` 技能包。包里是技能目录及其 `SKILL.md`。
3. 系统在独立的维护环境中读取 `SKILL.md`、安装依赖并验证，完成后技能进入所有会话共用的沙箱。

列表中可以看到每个技能的状态、来源（内置 / 已安装）和版本。管理员可以启用或停用、重新安装、卸载技能。卸载后，所有人的 Agent 会立即失去这项技能。

:::caution 安装前需要配置安装模型
技能安装由一个 Agent 完成，需要在 `docker/.env` 中配置 `KNOWFLOW_SKILL_INSTALLER_TENANT`（承担模型调用的账号）和 `KNOWFLOW_SKILL_INSTALLER_MODEL`（该账号下已配置的模型名）。两者缺一时，上传会被拒绝。
:::

### 填写技能变量

有些技能需要密钥、站点地址等环境变量，技能会在 `SKILL.md` 中声明。用户在 **Agent 技能** 页面点击对应技能的 **变量** 填写。

这些值只属于填写者本人，别人看不到也不受影响，并加密保存。已填的值不会再显示原文，留空表示保持不变，也可以点击 **清除**。

### 在聊天中使用技能

把回答方式切到 **Agent**，在输入框输入 `@`，在 **技能** 分组里选择要用的技能。每轮只能点名一个技能，只对当前消息生效。

## 长期记忆

长期记忆让助手跨会话记住用户的偏好和事实，例如“汇报材料一律用公司模板的配色”“我负责华东区域”。

### 开启

长期记忆**默认关闭**，需要三处都打开：

1. 管理员在 **我的记忆** 页面点击 **记忆配置**，打开「为所有人启用长期记忆」；
2. 聊天助手的高级设置中打开 **长期记忆**；
3. 用户在 **我的记忆** 页面打开「为我启用长期记忆」。

语义召回使用每个人自己的默认 Embedding 模型，请确认已配置。

### 记忆从哪里来

- 在对话里说“记住：……”，系统会原样记下；
- 在 **我的记忆** 页面手动 **添加**，类型包括个人信息、偏好、事实和在办事项；
- 管理员把记忆写入方式设为「自动提炼」后，系统会在对话结束后从内容中推断记忆。推断出的记忆进入 **待确认**，用户点「是的」才会被使用；点「不是」后，系统不会再推断同一条。

### 查看与管理

在 **我的记忆** 页面可以随时查看、编辑、删除、导出和清空记忆，也可以用 **整理** 合并相似条目。删除后的记忆不会再被使用。回答中会提示“本次使用了几条记忆”，并可以就地删除其中某一条。

## 运行中插话

Agent 处理长任务时，输入框不会锁住，可以继续补充要求：

| 操作 | 效果 |
| --- | --- |
| 回车，或点击「完成后发送」 | 排队，等当前回答结束后自动发出 |
| Mac 上 ⌘ + 回车；Windows / Linux 上 Alt + 回车 | 补充到当前任务，Agent 在本轮内就会看到 |
| Shift + 回车 | 换行 |

排队的消息显示在输入框上方，可以逐条改为「补充当前任务」，也可以撤回。刷新页面后，插话记录仍然保留。

## 思考开关

助手设置的 **模型与生成** 中有一个 **思考** 开关，统一控制普通问答、Agent、写作和视觉模型是否让模型先思考再回答。

- 开启：复杂问题更准，但首字明显变慢；思考过程会流式显示。
- 关闭：直接作答。v2.6.1 中视觉模型关闭思考后，首字从约 10 秒降到约 2 秒。

模型本身不支持思考时，这个开关不起作用。

## 部署与升级说明

- **沙箱**：`docker/.env` 中 `KNOWFLOW_SANDBOX_IMAGE` 一行即沙箱开关，注释掉即关闭；`COMPOSE_PROFILES` 中的 `sandbox` 请保留。v2.6.1 起默认只启动 KnowFlow Agent 沙箱，上游旧画布的代码沙箱移到 `ragflow-code-sandbox` profile，需要时再单独开启。
- **技能安装**：配置 `KNOWFLOW_SKILL_INSTALLER_TENANT` 与 `KNOWFLOW_SKILL_INSTALLER_MODEL` 后才能上传技能。
- **模型**：Agent 依赖支持原生 Tool Calling 的聊天模型，详见 [Deep Agent Skills 使用指南](./skills.md#常见问题)。

逐项变更见 [更新日志](../../发布记录/index.md)。
