# 知识库管理

知识库管理的树状结构（知识库内容树）是 KnowFlow v2.4.3 新增的组织能力。当知识库数量增多时，扁平的知识库列表难以管理。通过引入**文件夹树**，你可以像整理文件目录一样，把知识库分门别类地组织起来，并按文件夹进行统一授权。

## 什么是知识库树状结构

在知识库列表页，左侧从原来的扁平列表升级为**树状导航**：

- **文件夹**：支持父子层级嵌套，用于分类归组知识库
- **知识库**：可归属于某个文件夹，也可以不归类

树中有两个特殊的根节点：

| 节点 | 说明 |
| --- | --- |
| **全部** | 展示所有文件夹下的全部知识库 |
| **未分类** | 展示尚未归入任何文件夹的知识库 |

点击某个文件夹节点，右侧即展示该文件夹下的知识库卡片，文件夹名称旁会显示知识库数量徽标。文件夹路径也会以面包屑形式展示在列表上方。

## 管理文件夹

:::info 权限要求
创建、改名、移动、删除文件夹以及文件夹授权等操作，需要**平台超级管理员**或**组织管理员**权限。普通成员为只读视图。
:::

### 新建文件夹

1. 在树状导航顶部点击 **新建文件夹**
2. 在弹窗中填写文件夹名称，以及可选的描述
3. 确认后文件夹出现在树中

同一父级下的文件夹名称不可重复。

### 改名

在文件夹节点的 **⋯** 菜单中选择 **改名**，输入新名称即可。改名仅修改显示名称，不影响其层级路径。

### 移动

- **移动文件夹**：拖拽文件夹到新的父级，或通过 **⋯** 菜单选择 **移动**。系统会自动重算该文件夹及其整个子树的路径，并防止形成循环（不能移动到自己的子级下）。
- **移动知识库**：在知识库卡片的 **⋯** 菜单中选择 **移动到文件夹**，选择目标文件夹即可。

### 删除

在文件夹的 **⋯** 菜单中选择 **删除**。为避免误删，**非空文件夹（含子文件夹或知识库）不可直接删除**，需先清空或迁移其中内容。删除为软删除，同时会回收该文件夹上的授权。

## 文件夹级授权与权限继承

树状结构最大的价值在于**按文件夹批量授权**，无需逐个知识库配置。

- 文件夹可以像知识库一样，授予**用户、组织、协作组**查看 / 编辑 / 管理权限
- 权限沿路径**向下继承**：授予某个文件夹的权限，会自动作用于其下的所有子文件夹与知识库
- 一个知识库的最终权限，是其**自身授权**与**所有上级文件夹授权**的并集（取权限最高者）

**示例**：将「AI」文件夹的查看权限授予「产品团队」协作组后，`AI / RAG / 使用手册` 这个知识库会被产品团队自动可见，无需再单独授权。

授权继承与 RBAC 的整体权限模型保持一致，详见 [RBAC 权限管理](/docs/product-usage/rbac-permission)。

## 知识库导入导出

v2.4.3 将知识库导入导出能力从后台迁移到了产品前台：

- **导出**：选择知识库卡片，通过 **⋯** 菜单选择 **导出**，得到 ZIP 包
- **导入**：通过 **⋯** 菜单选择 **导入**，上传 ZIP 包，并可选择导入到指定文件夹

## 卡片布局优化

配合树状结构，知识库与聊天卡片在 v2.4.3 中也做了视觉优化：

- 卡片新增**彩色主题条**，便于快速区分
- 已授权的知识库卡片带**授权可视化徽标**，一眼即可看出授权状态
- 首页卡片与文件夹树布局整体对齐，浏览体验更统一

## 常见问题

**Q：不使用文件夹会影响现有知识库吗？**

不会。文件夹是可选能力，未归类的知识库统一出现在「未分类」节点下，原有使用方式不受影响。

**Q：为什么我看不到「新建文件夹」按钮？**

创建文件夹需要超级管理员或组织管理员权限。若你是普通成员，将只能浏览有权限的知识库。

**Q：把知识库移动到文件夹后，权限会变吗？**

移动后该知识库会额外继承目标文件夹（及其上级）的授权，其自身已有的授权仍然保留，最终按并集生效。
