# 知识库管理

知识库管理的树状结构（知识库内容树）是 KnowFlow v2.4.3 新增的组织能力。当知识库数量增多时，扁平的知识库列表难以管理。通过引入**文件夹树**，你可以像整理文件目录一样，把知识库分门别类地组织起来，并按文件夹进行统一授权。

目录也是 KnowFlow 权限模型的核心：超级管理员先建顶层目录并指定目录管理员，目录管理员再在目录里建知识库。完整规则见 [RBAC 权限管理](/docs/product-usage/rbac-permission)。

## 什么是知识库树状结构

在知识库列表页，左侧从原来的扁平列表升级为**树状导航**：

- **文件夹**：支持父子层级嵌套，用于分类归组知识库
- **知识库**：通常归属于某个文件夹；只有超级管理员可以把知识库放在根级（面包屑显示为「未分类」）

点击树顶部的 **全部**，右侧以卡片展示顶层文件夹和根级知识库；点击某个文件夹节点，右侧展示它的子文件夹与知识库卡片，文件夹名称旁会显示知识库数量徽标。文件夹路径以面包屑形式展示在列表上方。

目录树按权限裁剪：每个人只看到自己被授权的目录及通往它们的路径，知识库数量也只统计自己可见的部分。

## 管理文件夹

:::info 权限要求
- **顶层文件夹**只能由**超级管理员**创建。
- 在某个文件夹上拥有「管理」权限的人（目录管理员），可以在该文件夹及其子树内新建子文件夹、改名、移动、删除和授权。
- 其他人只能浏览被授权的内容。组织管理员身份本身不带来文件夹权限。
:::

### 新建文件夹

- **顶层文件夹**：超级管理员点击树顶部「文件夹」旁的 **+**。
- **子文件夹**：目录管理员在目标文件夹的 **⋯** 菜单中选择 **新建子文件夹**。

填写文件夹名称及可选描述，确认后文件夹出现在树中。

同一父级下的文件夹名称不可重复。

### 改名

在文件夹节点的 **⋯** 菜单中选择 **重命名**，输入新名称即可。改名仅修改显示名称，不影响其层级路径。

### 移动

- **移动文件夹**：拖拽文件夹到新的父级，或通过 **⋯** 菜单选择 **移动**。系统会自动重算该文件夹及其整个子树的路径，并防止形成循环（不能移动到自己的子级下）。目标位置必须是你管理的文件夹，移到根级只有超级管理员可以操作。
- **移动知识库**：在知识库卡片的 **⋯** 菜单中选择 **移动到文件夹**，选择目标文件夹即可。需要同时对该知识库和目标文件夹拥有「管理」权限。

### 删除

在文件夹的 **⋯** 菜单中选择 **删除**。为避免误删，**非空文件夹（含子文件夹或知识库）不可直接删除**，需先清空或迁移其中内容。删除为软删除，同时会回收该文件夹上的授权。

## 在文件夹内创建知识库

在当前文件夹拥有「管理」权限时，列表上方会出现 **创建知识库** 和导入入口。新建或导入的知识库直接归入当前文件夹，并自动继承文件夹上的全部授权。

没有「管理」权限时不显示创建按钮；在根级创建知识库只有超级管理员可以操作。

## 文件夹级授权与权限继承

树状结构最大的价值在于**按文件夹批量授权**，无需逐个知识库配置。

1. 在文件夹的 **⋯** 菜单中选择 **授权**；
2. 在「用户 / 组织 / 协作组」页签中搜索并选择授权对象；
3. 选择 **只读 / 编辑 / 管理**，点击 **授权**。

- 权限沿路径**向下继承**：授予某个文件夹的权限，会自动作用于其下的所有子文件夹与知识库
- 一个知识库的最终权限，是其**自身授权**与**所有上级文件夹授权**的并集（取权限最高者）
- 下级文件夹不能收窄上级继承的权限
- 把某个文件夹的「管理」授给某人，就是让他成为这个文件夹的目录管理员

**示例**：将「AI」文件夹的「只读」授予「产品团队」协作组后，`AI / RAG / 使用手册` 这个知识库会被产品团队自动可见，无需再单独授权。

授权继承与 RBAC 的整体权限模型保持一致，详见 [RBAC 权限管理](/docs/product-usage/rbac-permission)。

## 知识库导入导出

v2.4.3 将知识库导入导出能力从后台迁移到了产品前台：

- **导出**：选择知识库卡片，通过 **⋯** 菜单选择 **导出**，得到 ZIP 包
- **导入**：通过 **⋯** 菜单选择 **导入**，上传 ZIP 包，并可选择导入到指定文件夹

## 卡片布局优化

配合树状结构，知识库与聊天卡片在 v2.4.3 中也做了视觉优化：

- 卡片新增**彩色主题条**，便于快速区分
- 已授权的知识库卡片带**授权可视化徽标**，一眼即可看出授权状态
- 首页卡片与文件夹树布局整体对齐，浏览体验更统一

## 常见问题

**Q：不使用文件夹会影响现有知识库吗？**

不会。升级前没有归入文件夹的知识库仍保留在根级，可在「全部」中看到，原有授权不变。建议超级管理员逐步把它们移入对应目录，便于按目录统一授权。

**Q：为什么我看不到「新建文件夹」或「创建知识库」按钮？**

顶层文件夹只有超级管理员可以创建；子文件夹和知识库需要你对当前文件夹拥有「管理」权限。组织管理员身份不包含这项权限，请联系超级管理员授权。

**Q：把知识库移动到文件夹后，权限会变吗？**

移动后该知识库会额外继承目标文件夹（及其上级）的授权，其自身已有的授权仍然保留，最终按并集生效。
