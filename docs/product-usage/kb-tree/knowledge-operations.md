# 知识运营概览

知识运营概览把知识库上线后的使用效果集中到一个页面。运营人员可以查看问答是否有效、哪些知识被频繁使用、用户仍在反复询问哪些未解决问题，并把发现的问题转成可跟进的优化任务。

页面数据只统计当前账号有权查看的知识库。账号权限变化后，概览、明细和导出范围会同步变化。

## 访问入口

登录 KnowFlow 后，在左侧导航点击 **概览**，进入 **知识运营概览**。

在页面顶部可以切换统计时间范围。页面内的指标、趋势、排行和明细都会使用同一时间口径。

## 查看核心运营指标

顶部指标区用于快速判断知识库的整体使用情况：

| 指标 | 说明 |
| --- | --- |
| 问答总量 | 所选时间范围内的全部用户提问数量 |
| 活跃用户 | 产生问答行为的去重用户数 |
| 回答有效率 | 成功生成有效回答的问答占比 |
| 点赞率 | 获得正向反馈的回答占比 |
| 差评回答 | 收到负向反馈、需要重点复盘的回答数量 |

**问答活跃趋势**同时展示每天的问答量和活跃用户数，可以用来判断使用量增长、活动峰值和异常波动。

## 发现知识缺口

**知识缺口**会聚合未命中、低质量或收到负向反馈的相近问题，帮助运营人员从零散问答中找到重复出现的内容缺口。

每个问题簇会展示：

- 出现次数
- 影响用户数
- 涉及应用数
- 最近发生时间

点击问题簇可以下钻到相关问答记录，查看原始问题、回答摘要、反馈原因、关联应用和知识库，再决定补充文档、调整分块或优化问答配置。

## 查看热门知识和待处理事项

页面提供两个热门排行：

| 排行 | 统计口径 | 用途 |
| --- | --- | --- |
| 热门知识库 | 检索命中次数 | 识别高频业务领域和重点维护对象 |
| 热门文档 | 回答引用次数 | 找到最常支撑用户回答的内容 |

行动区域还会提示解析失败的文档和需要处理的知识问题。点击卡片可进入对应知识库或明细页面继续处理。

## 明细下钻

点击顶部指标、知识缺口或热门排行，可以进入运营明细。明细页支持：

- 按知识库、时间、状态和关键词筛选
- 查看问答记录、知识缺口、热门知识库和热门文档
- 从知识缺口继续查看关联的原始问答
- 在有权限时查看用户信息

明细和概览使用相同的 RBAC 权限范围。没有知识库查看权限的内容不会出现在页面或导出文件中。

## 知识优化与 AI 诊断

**知识优化**将需要处理的问题整理为任务队列。运营人员可以按信号类型、处理状态、知识库和关键词筛选，并执行以下操作：

- 对单条或多条问题发起 AI 诊断
- 查看基于问答反馈和检索命中的诊断结果及优化建议
- 将问题标记为已解决或忽略
- 将已处理问题重新打开

只有对相关知识库拥有编辑权限的账号才能执行诊断和更新状态。批量操作一次最多处理 100 条任务；AI 诊断一次最多提交 20 条，系统还会限制短时间内的提交频率。

:::tip 推荐处理顺序
优先处理高频知识缺口和差评回答。先查看关联问答与检索证据，再根据 AI 建议补充文档、调整分块或修改助手配置，最后将任务标记为已解决。
:::

## 导出运营报表

点击页面右上角的 **导出**，可以按当前筛选条件导出数据：

| 导出方式 | 格式 | 内容 |
| --- | --- | --- |
| 完整运营报表 | XLSX | 指标汇总、趋势、问答明细、知识缺口、热门知识库和热门文档 |
| 当前明细 | XLSX 或 CSV | 当前页签和筛选条件对应的数据 |

单次导出最多包含 10,000 条明细。超过上限时，文件中会写入截断提示。用户信息只会在当前账号具备相应查看权限且主动选择导出时出现。

## 日常运营建议

1. 每周查看问答量、有效率和差评回答的变化。
2. 从高频知识缺口下钻到原始问答，确认问题来自内容缺失、解析质量还是助手配置。
3. 使用 AI 诊断形成可执行建议，但在修改知识库前核对引用证据。
4. 优先维护热门文档，避免高频内容过期后影响大量回答。
5. 定期导出完整报表，保留阶段性运营记录并对比优化前后的效果。
