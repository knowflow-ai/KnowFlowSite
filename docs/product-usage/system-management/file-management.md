# 文件管理

文件管理用于维护后台文件资源。当前页面地址为 `/admin/management/files`，支持文件搜索、上传、下载、删除和分页查看。

> 产品截图预留：文件管理列表页。

## 列表字段

| 字段 | 说明 |
| --- | --- |
| 文件名 | 文件名称，并按文件类型显示图标 |
| 创建者 | 上传或创建该文件的用户 |
| 大小 | 文件大小 |
| 类型 | 文件扩展名或文件类型 |
| 创建时间 | 文件创建时间 |
| 操作 | 下载、删除 |

页面顶部支持按文件名搜索，刷新按钮可重新加载当前列表。

## 上传文件

点击**上传文件**，在弹窗中选择一个或多个文件后确认上传。

> 产品截图预留：上传文件弹窗。

上传区域支持多选文件，选择后会展示已选文件数量、文件名和大小。

:::info 支持格式
页面提示支持 PDF、DOC、TXT、图片等常见格式。实际可上传格式以服务端文件处理配置为准。
:::

## 下载文件

在文件行点击下载图标，浏览器会下载该文件。下载请求会直接获取二进制文件内容，并以原文件名保存。

## 删除文件

在文件行点击删除图标，确认后删除该文件。

:::warning 删除影响
删除文件前应确认该文件是否仍被知识库文档或业务流程使用。删除后无法从文件管理页面恢复。
:::

## 与知识库的关系

文件管理维护的是后台文件资源；知识库中的文档管理在**知识库管理**页面完成。需要查看知识库下的文档、分块数量或解析状态时，请进入知识库管理的“管理文档”弹窗。

## 当前页面不包含的能力

当前文件管理页不提供文件夹树、文件移动、重命名和批量删除入口。如需这些能力，应以实际产品界面或后续版本为准。
