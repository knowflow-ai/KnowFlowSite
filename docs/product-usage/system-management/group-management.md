# 协作组管理

协作组用于横向协作，适合跨部门项目组、客户专项组、临时任务组等场景。当前页面地址为 `/admin/management/groups`。

> 产品截图预留：协作组管理列表页。

## 协作组与组织的区别

| 对象 | 适合表达 | 是否有层级 | 授权效果 |
| --- | --- | --- | --- |
| 组织 | 公司、部门、小组等纵向结构 | 是 | 授权给当前组织及下级组织成员 |
| 协作组 | 跨部门项目、临时专项、客户小组 | 否 | 只授权给协作组成员 |

协作组需要选择所属组织，用于标识管理范围，但协作组本身不参与组织树层级。

## 列表字段

| 字段 | 说明 |
| --- | --- |
| 协作组名称 | 协作组显示名称 |
| 描述 | 协作组用途说明 |
| 所属组织 | 协作组归属的组织范围 |
| 成员数 | 当前协作组成员数量 |
| 创建时间 | 协作组创建时间 |
| 操作 | 管理成员、删除协作组 |

页面顶部支持按关键词搜索协作组，并可刷新当前列表。

## 创建协作组

点击**新建协作组**，填写：

| 字段 | 是否必填 | 说明 |
| --- | --- | --- |
| 协作组名称 | 是 | 项目或专项名称 |
| 描述 | 否 | 协作组用途说明 |
| 所属组织 | 是 | 该协作组归属的组织范围 |

> 产品截图预留：创建协作组弹窗。

## 管理成员

在协作组行点击成员图标，进入成员管理弹窗。成员列表展示用户名、邮箱、加入时间和操作。

> 产品截图预留：协作组成员管理弹窗。

### 添加成员

点击**添加成员**，从用户列表中选择用户后确认。下拉框会过滤已在当前协作组中的成员。

### 移除成员

点击成员行删除按钮可将用户移出协作组。移出后，该用户会失去通过该协作组获得的知识库权限。

## 删除协作组

点击删除图标后确认删除协作组。删除协作组会使该组成员不再通过该协作组获得知识库权限。

## 使用建议

- 项目成员来自多个部门时，优先使用协作组。
- 项目结束后及时移除成员或删除协作组。
- 给协作组授权知识库时，只影响组内成员，不会影响其所在组织的其他用户。
- 长期稳定的部门关系应放在组织架构中维护。
