# 用户配置

用户配置用于查看和调整用户的模型配置。当前页面地址为 `/admin/management/user-config`，支持按用户名搜索、查看管理员默认设置，并为单个用户选择对话模型和嵌入模型。

> 产品截图预留：用户配置列表页。

## 管理员默认设置

页面顶部会展示管理员默认设置，包括：

- 对话模型
- 嵌入模型

如果用户未单独配置模型，可以使用默认设置。

## 列表字段

| 字段 | 说明 |
| --- | --- |
| 用户名 | 用户显示名称 |
| 邮箱 | 用户邮箱 |
| 对话模型 | 用户当前对话模型 |
| 嵌入模型 | 用户当前嵌入模型 |
| 更新时间 | 配置更新时间 |
| 操作 | 编辑用户配置 |

页面顶部支持按用户名搜索，刷新按钮可重新加载当前列表。

## 编辑用户配置

点击用户行的编辑图标，打开**编辑用户配置**弹窗。

> 产品截图预留：编辑用户配置弹窗。

弹窗会展示当前用户，并可配置：

| 字段 | 说明 |
| --- | --- |
| 对话模型 | 用于问答和对话生成的模型 |
| 嵌入模型 | 用于知识库向量化和语义检索的模型 |

每个字段都可以选择**使用默认**，表示该用户不单独覆盖管理员默认配置。

## 模型来源

可选模型来自后台可用模型列表：

- `llm`：对话模型列表
- `embedding`：嵌入模型列表

页面会优先显示模型名称；如果找不到名称，则显示模型 ID。

## 配置建议

- 新用户优先使用默认配置，减少维护成本。
- 对检索质量要求较高的用户，应确认嵌入模型与知识库解析配置匹配。
- 对回答质量要求较高的用户，可单独配置更强的对话模型。
- 调整嵌入模型前，应评估已有知识库是否需要重新向量化。

## 常见问题

### 选择“使用默认”会清空用户模型吗？

是。提交时该字段不再保存用户级覆盖配置，用户会回到管理员默认设置。

### 为什么列表里显示的是模型 ID？

当模型 ID 没有在可用模型列表中匹配到名称时，页面会直接显示模型 ID。

### 用户配置会影响已有知识库吗？

对话模型会影响问答生成；嵌入模型主要影响文档向量化和检索。已完成向量化的知识库是否需要重新处理，应按实际业务和模型切换策略评估。
