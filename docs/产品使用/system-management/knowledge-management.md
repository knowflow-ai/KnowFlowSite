# 知识库管理

知识库管理用于统一维护系统中的知识库资源。当前页面地址为 `/admin/management/knowledge`，支持搜索、新建、导入导出、管理文档、管理权限和删除知识库。

> 产品截图预留：知识库管理列表页。

## 列表字段

| 字段 | 说明 |
| --- | --- |
| 选择框 | 用于选择一个或多个知识库执行导出 |
| 知识库 | 知识库名称 |
| 描述 | 知识库说明 |
| 文档数 | 知识库下的文档数量 |
| 创建者 | 创建该知识库的用户 |
| 创建时间 | 知识库创建时间 |
| 操作 | 管理文档、管理权限、删除 |

页面顶部支持关键词搜索、刷新、新建知识库、导入和导出。

## 新建知识库

点击**新建知识库**，填写名称和描述后确认。

> 产品截图预留：创建知识库弹窗。

| 字段 | 是否必填 | 说明 |
| --- | --- | --- |
| 名称 | 是 | 知识库名称 |
| 描述 | 否 | 知识库用途说明 |

## 导出知识库

勾选一个或多个知识库后，点击**导出**。系统会通过后台接口生成 ZIP 包并下载。

导出文件可用于备份、迁移或在其他环境中导入。导出按钮会显示当前已选择的知识库数量。

## 导入知识库

点击**导入**，上传通过导出功能生成的 ZIP 文件。系统会导入知识库及其文档，并在完成后提示成功和失败数量。

> 产品截图预留：导入知识库弹窗。

:::info 导入文件要求
导入文件必须是 ZIP 压缩包，并建议使用 KnowFlow 导出功能生成的文件。
:::

## 管理文档

点击知识库行的设置图标，打开**管理文档**弹窗。文档列表展示：

| 字段 | 说明 |
| --- | --- |
| 文档 | 文档名称 |
| 解析状态 | 已完成、解析中、未解析或待处理 |
| 上传日期 | 文档上传时间 |
| 分块 | 文档解析后的分块数量 |
| 操作 | 删除文档 |

> 产品截图预留：管理文档弹窗。

当前页面主要用于查看和删除知识库文档。文档解析操作以实际界面开放的按钮为准。

## 管理权限

点击知识库行的盾牌图标，打开**管理权限**弹窗。权限管理分为三个页签：

| 页签 | 授权主体 | 适用场景 |
| --- | --- | --- |
| 用户 | 单个用户 | 临时特例或精确授权 |
| 组织 | 组织节点 | 部门、事业部、子公司等纵向范围 |
| 协作组 | 协作组 | 跨部门项目或专项协作 |

> 产品截图预留：知识库权限弹窗。

### 权限等级

| 权限 | 页面名称 | 说明 |
| --- | --- | --- |
| `read` | 查看者 | 可以查看和检索知识库 |
| `write` | 编辑者 | 可以维护知识库内容 |
| `admin` | 管理员 | 可以管理知识库及授权 |

### 授权和撤销

在对应页签中选择用户、组织或协作组，再选择权限等级并点击**授权**。已授权列表会展示主体名称和权限等级，点击**撤销**可移除该授权。

:::info 组织授权范围
对组织授权时，权限作用于当前组织及所有下级组织成员。
:::

:::tip 权限合并规则
同一用户可能同时通过用户、组织、协作组获得权限。系统会使用所有有效授权中的最高权限作为最终权限。
:::

## 删除知识库

点击删除图标后确认删除知识库。删除知识库会同时删除其文档。

:::warning 删除影响
知识库删除后无法从管理页面恢复。删除前建议先导出备份，并确认该知识库没有被业务应用调用。
:::
