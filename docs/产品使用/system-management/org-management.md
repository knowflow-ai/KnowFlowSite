# 组织架构

组织架构用于维护企业纵向层级，例如公司、事业部、部门、小组。当前页面地址为 `/admin/management/orgs`。

> 产品截图预留：组织架构列表页。

## 页面字段

| 字段 | 说明 |
| --- | --- |
| 组织名称 | 按树形层级展示组织，支持展开和收起 |
| 累计成员数 | 当前组织及所有下级组织的累计成员数 |
| 组织管理员邮箱 | 当前组织管理员邮箱 |
| 描述 | 组织说明 |
| 操作 | 创建子组织、管理成员、删除组织 |

:::info 累计成员数
累计成员数包含当前组织和所有下级组织成员。对组织授予知识库权限时，默认作用于当前组织及所有下级组织成员。
:::

## 新建组织

点击**新建组织**，填写组织名称、描述，并选择父组织：

- 选择“无”时创建根组织。
- 选择已有组织时创建该组织的下级组织。
- 在组织行点击加号时，会默认以该组织作为父组织创建子组织。

> 产品截图预留：创建组织弹窗。

## 管理成员

在组织行点击成员图标进入成员管理弹窗。成员列表展示：

| 字段 | 说明 |
| --- | --- |
| 用户名 | 成员名称 |
| 邮箱 | 成员邮箱 |
| 所属组织 | 成员实际归属组织 |
| 身份 | 普通成员或组织管理员 |
| 来源 | 直属成员或下级成员 |
| 主组织 | 是否为该用户主组织 |
| 加入时间 | 成员加入时间 |

> 产品截图预留：组织成员管理弹窗。

### 添加成员

点击**添加成员**，选择用户，并设置身份：

- **普通成员**：获得组织成员身份。
- **组织管理员**：可管理当前组织及下级组织范围内的用户和资源。

成员下拉框会过滤掉已经在当前组织成员列表中的用户。

### 设置组织管理员

直属成员可以在成员列表中切换为组织管理员或取消管理员。组织管理员身份作用于该组织节点，管理范围覆盖当前组织及所有下级组织。

### 移除成员

直属成员可以从当前组织移除。下级成员来自下级组织，只能到其直属组织中维护。

:::warning 自己的管理员身份
页面会避免组织管理员直接取消自己的管理员身份，防止误操作导致失去当前管理入口。
:::

## 删除组织

点击删除图标后确认删除组织。删除前应先确认组织下是否还有成员、下级组织或正在使用的知识库授权。

## 使用建议

- 按真实企业层级建立组织树，避免把临时项目放进组织树。
- 部门负责人适合设为组织管理员。
- 跨部门项目使用**协作组管理**，不要为临时项目创建长期组织节点。
- 给组织授权知识库时，注意该权限会覆盖下级组织成员。
