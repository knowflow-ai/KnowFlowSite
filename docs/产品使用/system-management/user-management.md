# 用户管理

用户管理用于维护 KnowFlow 平台用户。当前页面地址为 `/admin/management/users`，支持按关键词搜索用户、刷新列表、新建用户、编辑用户名、重置密码和删除用户。

> 产品截图预留：用户管理列表页。

## 列表字段

| 字段 | 说明 |
| --- | --- |
| 用户名 | 用户显示名称 |
| 邮箱 | 用户登录邮箱 |
| 主组织 | 用户的主要组织归属 |
| 创建时间 | 用户创建时间 |
| 更新时间 | 用户最近更新时间 |
| 身份 | 超级管理员、组织管理员或普通用户等身份标签 |
| 操作 | 编辑、重置密码、删除 |

页面顶部提供搜索框，输入关键词后会按用户信息检索，并自动回到第一页。刷新按钮可重新拉取当前列表。

## 新建用户

点击**新建用户**，填写以下信息：

| 字段 | 是否必填 | 说明 |
| --- | --- | --- |
| 用户名 | 是 | 用户显示名称 |
| 邮箱 | 是 | 用户登录账号 |
| 密码 | 是 | 初始登录密码 |
| 主组织 | 是 | 用户默认所属组织 |

> 产品截图预留：创建新用户弹窗。

新建用户时必须选择主组织。主组织来自组织架构树，弹窗中会按层级展示组织名称。

:::tip 组织管理员创建用户
组织管理员可以创建用户。创建时应将用户放入自己管理范围内的组织，便于后续按组织进行权限授权和管理。
:::

## 编辑用户

在用户行悬停后点击编辑图标，可以修改用户名。邮箱作为登录账号展示为不可编辑。

> 产品截图预留：编辑用户弹窗。

## 重置密码

点击钥匙图标可为用户重置密码。弹窗需要输入新密码并再次确认，两次密码一致后才能提交。

> 产品截图预留：重置密码弹窗。

## 删除用户

点击删除图标后，系统会弹出确认框并展示用户邮箱。确认后删除该用户。

:::warning 删除影响
删除用户会影响该用户的组织成员关系、协作组成员关系和知识库访问结果。删除前建议确认该用户不再需要访问系统资源。
:::

## 常见问题

### 用户身份在哪里设置？

超级管理员身份由系统角色决定；组织管理员身份在**组织架构**的成员管理中设置，不是在用户管理页单独创建。

### 为什么新建用户必须选择主组织？

主组织用于确定用户默认组织归属，也便于后续按组织进行知识库授权、组织管理员管理和成员统计。

### 用户可以加入多个组织吗？

可以。用户管理页展示主组织；更多组织成员关系在**组织架构**中维护。
