# 更新日志


## [v2.6.1] - 2026-09-30

### 新增
- 多跳检索（SAG）换成 Milvus 版引擎：SAG 的结果和原生检索融合，不再整体替换原生结果；开了 SAG 的聊天会保留更多片段，并使用 SAG 专用的回答指引
- SAG 通过 KnowFlow 的模型代理调用模型：对话和重排用知识库所属账号的默认模型，嵌入用知识库自己的嵌入模型，不再单独同步和保存模型密钥
- SAG 图谱打开更快；点击节点可以看事件摘要、发生时间和相关实体，还能跳转到原文
- SAG 检索策略改到助手设置里选，检索测试页也可以每次单独选
- ColPali 视觉检索改用 Milvus 原生多向量检索（MAX_SIM）；删除或重新解析文档时，会同步清理对应页面
- Milvus 升级到 3.0.2，支持从 2.6 原地升级；文档库启用新的存储结构（分词不区分大小写、标签等字段改为数组），已有的库在启动后自动在线迁移，检索不中断

### 优化
- 视觉模型遵守助手的「思考」开关，首字从约 10 秒降到约 2 秒；打开思考时，推理过程会流式显示
- ColPali 视觉检索与文本检索同时进行；检索时调用重排序模型不再阻塞服务
- Milvus 下更新分块改为只改变动的字段，分块列表翻页更快，标签统计覆盖全部分块
- 滚动条改为细滚动条，侧栏菜单只在鼠标悬停时显示滚动条
- 部署默认只启动 KnowFlow Agent 沙箱，不再同时拉起上游旧画布的特权代码沙箱
- PostgreSQL 镜像换回官方 postgres:16（Debian），不再带 pgvector 扩展，已有数据卷直接复用；新装不再多建 sag 空库，已有部署里旧版 SAG 留下的 sag 库可手动删除

### 修复
- 修复系统管理后台新建用户失败
- 修复删除知识库后，它在 SAG 里的数据没有清掉
- 修复检索测试页 SAG 检索链路面板不显示统计；修复 SAG 检索测试互相等待直到超时
- SAG 抽取只得到事件、没有实体时给出提示；连不上 SAG 服务时说明原因
- 修复 Milvus 过滤条件的注入问题，以及标签删除、重命名不生效
- 修复聊天引用的 md 等非 PDF 文档点开后无法预览
- 修复消息内容为空时聊天页整页崩溃
- 修复 Agent 模式的回答被空回答兜底覆盖
- 修复硅基流动等走 LiteLLM 的模型在聊天时报错
- 修复同一个模型在多个账号下登记的类型不同时判定错误，导致开启 ColPali 的助手保存时报「需要 VLM」
- 修复对外 API 用 API key 访问一律报错；修复数据源同步遇到带元数据的文档时整次失败
- 问数：修复 MySQL 数据源上的发布检查指标样本和问数重算一律报错

## [v2.6.0] - 2026-09-25

### 新增
- 办公 Agent 可以直接交付 Word、PowerPoint、Excel 文件：内置三个办公文档技能，在隔离沙箱中生成，文件在对话里显示为可点击的卡片，抽屉内就地预览
- Agent 沙箱默认开启：每个会话一个断网的隔离工作区，上传的附件自动放进工作区供 Agent 读取，删除会话时一并清理
- 技能目录：管理员可上传技能包，在独立维护环境中安装；技能可声明所需环境变量（站点、个人两层填写）与版本；已装技能进入会话沙箱，可在聊天框用 @ 点名本轮使用
- 长期记忆：跨会话记住用户的偏好与事实，推断出的记忆先挂起等用户确认，支持语义召回；独立的记忆页面，可开关、编辑、清空
- 插话：Agent 运行中也能继续输入，回车排队到下一轮，组合键补进当前轮，「完成后发送」到点自动发出，刷新后插话记录仍在
- 助手级「思考」开关，统一控制普通问答、Agent 与写作是否让模型思考
- 聊天框回答方式收成两项，能力、技能与文档统一用 @ 就地点名
- 写作工作区的稿件可以直接修改并保存
- 文档搜索支持精确与正则匹配，一次找全并给出命中数；结构化抽取不再限定台账与 Excel
- 问数建模：字段、关系、指标旁可「用数据核对」，查看样例行与列画像；指标可手工新建（原子、复合），表达式免写；没有主标识的表也能被问到；一对多连接按主标识去重算对，不再一刀切拒绝
- 问数查询：「满足条件的实体占比」「某个实体排第几」成为受治理写法；层级树收进发布版本，问数期不再读客户库

### 优化
- 界面统一为 Ant Design 5 规范：主色改为晴空蓝，页面标题、弹窗、提示、删除确认、空状态统一；设置页与系统管理套用主应用外壳；问数页面共用同一套令牌；暗色主题下线
- 聊天页、知识库文件列表、记忆页、知识库卡片重新排版
- Agent 长任务稳定性：上下文按模型真实窗口自动压缩，并按服务商实际用量校准计数；压缩碰不到的大工具结果按窗口预算截断；回答撞上输出上限时交出已写内容并注明；流式无进展超时、失败重试与降级回答；回合预算提高到 30 次，用尽时给出答案而不是报错
- 普通问答被截断时的提示改为说明是「单次输出上限」，不再误导去调上下文长度
- 写作首字从 80~90 秒降到约 2 秒
- Agent 步骤列表：连续调用同一工具合并为一行，工具显示中文名
- 问数：提示词规则收敛，改由编译器检查与受治理写法保证正确性；业务词典与取值业务名进入提示，基线静默错答归零；模型超时或候选被拒时直接拒答，不再退给规则兜底；SQL 读超时默认 60 秒，整问有总时长预算；问数默认不让模型思考
- 数据库连接被回收后立即重连，知识库详情等接口不再多等 1 秒

### 修复
- 修复 Agent「卡死」：实为未设生成上限导致的失控生成
- 修复沙箱命令从未真正执行、产物只收 xlsx、上一轮的文件被重复交付
- 修复附件写作请求一律失败；「抽取并生成 Excel」的请求被写作流程截走
- 修复预算用尽时把工具调用当回答吐给用户，以及长任务在第 23 轮被步数上限截断
- 修复回答方式跑完一轮退回普通问答、助手配置未加载完时模式来回跳
- 修复切换知识库时详情页显示上一个知识库的缓存
- 修复搜索页整页变灰、搜索框看不见、工作区被拦腰截断
- 修复 MinerU、PaddleOCR 等五处模型配置不跟随系统模型源
- 修复技能目录不可用时输入 @ 整页报错、技能名被当成版本显示
- 问数：修复 AI 建模重跑失败、列名带空格建模失败、字段改名不保存、删除关系报 500、点「应用」白屏、BETWEEN 区间被误拒、占比分母被同一维度过滤成分子本身
