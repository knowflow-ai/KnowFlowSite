# 更新日志


## [v2.4.6] - 2026-07-25

### 新增
- 新增知识优化中心与 AI 辅助诊断：基于问答反馈和检索命中分析问题，支持单条及批量诊断并提供优化建议
- 新增概览数据下钻与运营报表导出，支持按知识库、时间和问题类型筛选，并按当前账号权限过滤数据范围
- 新增博查联网搜索，助手可配置博查 API Key，将网络搜索结果作为知识库问答的补充
- 新增 ColPali 文档级视觉融合检索：同一知识库可混合视觉文档与普通文档，通过 RRF 合并视觉和文本检索结果
- 新增管理员按用户配置默认模型，支持模型授权校验、凭据同步和配置即时生效
- 新增企业微信网页授权登录，完善回调校验、账号映射及用户模型初始化流程

### 优化
- 优化 Milvus 向量维度探测与路由：持久化知识库维度并增加正负缓存，减少重复扫描和模型调用
- 优化 Docker 构建缓存与镜像体积，完善国内镜像源、NLTK 和 Tika 依赖下载，并支持通过开关选择构建源
- SAG 调整为按需启用的独立部署能力，基础部署默认不再启动，启用时可复用现有 PostgreSQL 数据卷
- 收敛旧版首页和知识库配置入口，统一导航、概览、聊天设置及管理后台的交互体验

### 修复
- 修复 Wiki 生成任务取消、部分失败及并发更新时的状态错乱和内容覆盖问题
- 修复 Wiki 交叉链接直接显示拼音 slug 的问题，统一使用可读页面标题
- 修复 AI 诊断后台任务在取消、失败、并发执行及对象存储访问场景下的稳定性问题

## [v2.4.3] - 2026-07-10

### 新增
- 新增 LLM Wiki 能力，支持将知识库文档自动编织为实体页、概念页与摘要页三类互链 Wiki，并支持增量生成、删文档自维护与 Wiki 健康体检（详见 [LLM Wiki 使用指南](../product-usage/retrieval-enhancement/llm-wiki.md)）

### 优化

- 优化 检索测试页复用「使用知识图谱」开关走 SAG，移除独立下拉，交互更一致
- 优化 开启 SAG 时自动同步 RAGFlow 默认嵌入与 LLM 模型到 SAG 服务，用户无需重复配置
- 优化 Helm 部署支持分布式任务执行（web/executor 拆分）与多副本高可用

### 修复
- 修复 Wiki 路由 RBAC 权限校验补全问题
- 修复 SAG 检索引用溯源与 chunk 高亮对齐传统 RAG 的问题
- 修复 RBAC 去 tenant_id 隔离后文件夹可见性与缓存问题
